# Applied AI & Robotics Lab

*Learn. Build. Experiment. Evaluate. Share.*

An independent engineering lab exploring modern AI, computer vision, robotic perception, autonomous navigation, and efficient model deployment through reproducible experiments.

## Learning program

Two eight-hour sessions each week, one technical concept per session. The proposed schedule is Tuesday and Thursday.

| Phase | Hours |
| --- | ---: |
| Research | 1 |
| Theory and architecture | 1.5 |
| Core implementation | 1.5 |
| Practical mini-project | 2 |
| Evaluation | 1 |
| Documentation and publication | 1 |

## Repository organization

- `labs/` — independent, reproducible experiments
- `templates/` — experiment and article templates
- `shared/` — reusable utilities and resource documentation
- `.github/` — issue and pull request templates

## Definition of done

A lab has a documented research question, a working implementation, reproducible setup, measured results, limitations, references, and a technical article linked from the website Playground. Explain the concept independently and record actual hours and understanding before closing the issue. Scope complex concepts to an achievable experiment rather than claiming mastery in a day.

## Related projects

- [TISHTAR](https://github.com/sepideh-shamsizadeh/tishtar-robot) — physical autonomous robot
- [MiniDL](https://github.com/sepideh-shamsizadeh/deep-learning) — deep learning from scratch

Use ROS 2 Jazzy, Gazebo and reference robots for simulation while TISHTAR is under development. Transfer validated methods to the physical robot where relevant.

## Reproducibility and responsible publishing

Pin dependencies per lab, record hardware and software versions, credit sources and respect dataset/model licenses. Do not commit secrets, private data or large model weights. Report actual measurements and limitations.
